## Suggested learning order
1. Inspect raw data.
2. Practise Excel cleaning tools and text functions.
3. Try sorting, filtering, duplicates, blanks, and data types.
4. Repeat the workflow in Power Query.
5. Document the before/after result and assumptions.

Community repositories can change over time. Check each repository's README and license before reusing or redistributing its files. The customer-order data included in this folder is synthetic.
