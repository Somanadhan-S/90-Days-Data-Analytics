# Upload this folder to GitHub

1. Open https://github.com/Somanadhan-S/90-Days-Data-Analytics
2. Open `Month-01-Excel`.
3. Choose **Add file → Upload files**.
4. Upload the contents of this folder under `Week-02-Data-Cleaning-Power-Query`.
5. Keep both CSV files inside a `data` subfolder. If the browser uploader does not preserve nested folders, create `data` first and upload the CSVs there.
6. Commit message: `Add Week 02 Excel data cleaning and Power Query resources`.
7. Open the folder after committing and check that every file opens correctly.
